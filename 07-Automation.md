## 1. n8n

**GitHub:** [n8n-io/n8n](https://github.com/n8n-io/n8n)

| Feature | Details |
|---------|---------|
| **What it does** | Workflow automation platform |
| **Best for** | Connecting apps and automating tasks |
| **Platform** | All platforms (Docker) |
| **Installation** | `docker run -it --rm --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n` |
| **Pros** | Free, 400+ integrations, self-hosted |
| **Cons** | Complex workflows need learning |
| **Rating** | ⭐⭐⭐⭐⭐ |

## Quick Start Guide

### n8n (Recommended for most users)
```bash
# Install with Docker
docker run -it --rm --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n

# Open http://localhost:5678
```

### IFTTT (Easiest)
1. Go to ifttt.com
2. Create account
3. Connect services
4. Create applets

### AutoHotkey (Windows)
1. Download from autohotkey.com
2. Install
3. Write scripts
4. Assign hotkeys
