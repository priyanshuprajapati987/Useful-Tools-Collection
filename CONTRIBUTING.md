## 🚀 Getting Started

1. **Fork** the repository
2. **Clone** your fork:
   ```bash
   git clone https://github.com/your-username/Useful-Tools-Collection.git
   ```
3. **Create a branch**:
   ```bash
   git checkout -b feature/add-new-tool
   ```
4. **Make your changes**
5. **Commit** and **push**
6. **Create a Pull Request**

## ✅ Quality Guidelines

### Tool Requirements

- ✅ **Free** or has a generous free tier
- ✅ **Open source** (preferred) or freeware
- ✅ **Actively maintained** (updated in last 6 months)
- ✅ **Working** and tested
- ✅ **Unique** - doesn't duplicate existing tools

### Writing Quality

- ✅ Clear, concise descriptions
- ✅ Accurate installation commands
- ✅ Honest pros/cons
- ✅ Proper formatting
- ✅ No typos or grammar errors

### Rating Scale

| Rating | Meaning |
|--------|---------|
| ⭐⭐⭐⭐⭐ | Exceptional - Must have |
| ⭐⭐⭐⭐ | Great - Highly recommended |
| ⭐⭐⭐ | Good - Solid choice |
| ⭐⭐ | Fair - Has limitations |
| ⭐ | Poor - Not recommended |

## 🔧 Pull Request Process

### Before Submitting

- [ ] Tool is not already in the collection
- [ ] Tool meets quality guidelines
- [ ] Format matches existing entries
- [ ] Installation command works
- [ ] Links are valid

### PR Title Format

```
Add [Tool Name] to [Category]
```

Example:
```
Add Ollama to AI & ML
```

### PR Description

```markdown
## What does this tool do?
[Brief description]

## Why should it be included?
[Reason]

## Checklist
- [ ] Tool is free/open source
- [ ] Actively maintained
- [ ] Format matches existing entries
- [ ] Links are valid
```

## 📋 Code of Conduct

### Do's

- ✅ Be respectful
- ✅ Help others
- ✅ Provide accurate information
- ✅ Test tools before adding

### Don'ts

- ❌ Add paid-only tools
- ❌ Add malware or suspicious tools
- ❌ Spam or self-promote excessively
- ❌ Modify others' contributions without permission
